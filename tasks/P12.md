# P12 — Default zoom and sprite scale (AoE2 clash framing)

**Status:** done  
**Builder:** Composer 2.5 (P12b)

## Goal

Default camera zoom and unit scale so the opening mid-map 8v8 clash fills the playfield like Age of Empires II: DE — infantry thumb-sized, not postage stamps in void.

## Changes

### `src/main.ts`
- Default `input.halfH` **8 → 5.0** (closer orthographic half-height).
- Pan **z: MAP × 0.48 → MAP × 0.52** so the camera centers on the clash centroid (fighters spawn around mid-map, not the old slightly-north bias).

### `src/input.ts`
- Minimum zoom clamp **7 → 4** (`Math.max(4, …)`). Pinch/wheel pan math unchanged (still scales with `halfH`).

### `src/render.ts`
- Infantry/unit draw scale **1.9/2.05 → 2.15/2.25** world units (within 1.8–2.2 target).
- Building/hall target height **3.2 → 3.0** world units.

### `index.html`
- Empty `data:,` favicon to silence automatic `/favicon.ico` 404 in critic harness.

### `scripts/measure.mjs`
- Chrome launch args disable headless 30 Hz `requestAnimationFrame` cap so FPS probe reflects real loop speed (was falsely reporting 30 fps).
