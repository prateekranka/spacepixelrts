# P33 — Unmissable opening bolt streaks

**Builder:** Composer 2.5 · **Gap from:** `tasks/P32-critic.md`

## Problem

P32 separated the wings but the critic saw zero readable projectiles — green and blue ranks faced off with no bolt streaks, muzzle flashes, or impact VFX crossing the gap.

## Changes

- **Opening clash cadence:** `tick < 240` + `openingClashEnt` → strike cooldown **0.32s**, bolt speed **6.0**, bolt `life` **1.4**; +0.95 range bonus extended to full opening window.
- **Bolt billboard:** scale **2.05** (was 0.92); draw **two** instances per bolt (head + 0.45 along velocity) for streak read.
- **Atlas `bolt-sting` / `bolt-beam`:** fat white core + civ-bright rim (Helion gold-green, Kryos cyan); fully opaque, no 16×16 speck.
- **Muzzle pop:** entity `iFlash` **0.55** while `cooldown > 0.2` (was 0.22 @ >0.55).
- `colPitch` / camp coords unchanged.

## Verification

`critic/out/p33.png` — p99 **4.2 ms**, probe **0.2.8-wave1**, 58 ents. ≥7 bright bolt streaks (white core + cyan/gold-green rims) visible in the gap between green and blue wings; muzzle flashes on firing ranks. Deployed to https://spacepixelrts.pages.dev
