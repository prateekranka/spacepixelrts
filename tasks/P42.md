## Single biggest Wave 2 gap

**No playable match arc — the skirmish is still a tableau with RTS verbs, not an empire you can grow.**

AoE2:DE depth needs a loop: gather → house → age → produce → siege → win. Today:

- **Epochs / age-up** are in `docs/DESIGN.md` §4 but absent from sim + HUD (no `AgeUp`, no epoch gates).
- **Win / lose** (destroy enemy Nexus) is unspecified in code — no defeat banner, no match end.
- **Empire production is blocked** — player starts **22/20 pop** so `tryTrain` refuses new units; macro cannot begin.
- **Enemy pressure is delayed** — scripted AI only attack-moves your Nexus after 6+ military (`stepAi`); player can ignore base macro entirely during the opening minute.

Wave 1 sold the fight; Wave 2 must sell **ruling** — fix pop cap, add epoch + production queue, wire win/lose, and make the enemy marshal threaten the player's Nexus while the player is macroing.
