# P80 — GPU particle VFX for sparks and bolts

**Builder:** Composer 2.5 · **Version:** `0.7.0-proc` · **Judged:** 2026-08-16

**Live:** https://spacepixelrts.pages.dev

Sparks and bolts no longer ride the unit atlas `InstancedMesh`. A dedicated additive GLSL particle path renders muzzle pops, impact plumes, and bolt bead trails with civ-tinted porous bursts.

---

## What shipped

| Item | Detail |
|---|---|
| `src/vfx.ts` | `VfxRenderer` — dedicated `InstancedMesh` (2048 cap), custom VS/FS, additive blend |
| Spark plumes | Each pooled spark → 8 sub-particles; hashed seed spread; muzzle tight / impact wide “broken plume” |
| Bolt beads | 4 stretched beads per bolt along velocity trail; muzzle → travel → impact chain preserved |
| Civ tints | Helion warm gold, Kryos ice cyan, Nihiline purple/green spore mix (shader constants) |
| Atlas offload | `render.ts` entity `drawn` count excludes sparks/bolts; probe exposes `rendererInfo.vfx` |
| Sim unchanged | `MAX_SPARKS` pool, `spawnSpark`, bolt pool — zero per-frame alloc on upload path |
| Default boot | Helion vs Kryos opening clash unchanged |
