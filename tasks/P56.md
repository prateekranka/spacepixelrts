## Gap (from P54)

## Changes

| Area | Result |
|---|---|
| **`issue()` spread** | When `ids.length > 1` and order is `Move` or `AttackMove`, each unit gets a hex-ish grid offset around the click. Spacing `clamp(maxRadius × 2.6, 0.7, 1.1)` tiles. |
| **Single-unit** | Unchanged — one destination, same pathfind. |
| **Buildings** | Still set rally to the click (no spread). |
| **Opening clash** | Spawn/rank setup untouched; Attack holds at ticks 0–239 unchanged. |
