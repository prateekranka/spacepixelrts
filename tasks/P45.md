# P45 — Victory and defeat banners + stable command deck

**Builder:** Composer 2.5 · **Bar:** `docs/DESIGN.md` §8 — win/lose when a Nexus falls · **Shipped:** 2026-08-16

**Live:** https://spacepixelrts.pages.dev · **Version:** `0.3.2-wave2`

---

## Problem (from P44)

DESIGN §8 requires a victory/defeat banner when a Nexus is destroyed — not a blank pause. P44 critic noted `renderCmds` rebuilt `#cmds` every frame via `innerHTML`, detaching buttons so Playwright and iPad taps missed Age Up / Train Worker.

---

## Changes

| Area | Fix |
|---|---|
| **`World.winner`** | `-1` in play · `0` player win · `1` enemy win. Set when a team has no living `Kind.Hall` with `hp > 0` and `progress >= 1`. Once set, never flips. Checked in `kill()` and end of `step()`. |
| **`main.ts` probe** | `winner` published on `window.__STARHOLD__`. |
| **`hud.ts` match end** | Centered pixel panel overlay: **VICTORY** / **DEFEAT** with subtitle (“Enemy Nexus shattered” / “Your Nexus is ash”). Does not black out the canvas; sim keeps ticking. |
| **`hud.ts` renderCmds** | Signature string of button set; skip `innerHTML` unless signature changed. Buttons stay in DOM across frames. |
| **`main.ts`** | `VERSION = 0.3.2-wave2`. |

Epoch costs, pop/housing (P43/P44), and opening tableau unchanged.
