# P68 — Civ picker so Nihiline can appear in the 1v1

**Builder:** Composer 2.5 · **Version:** `0.6.0-wave5` · **Judged:** 2026-08-16

**Live:** https://spacepixelrts.pages.dev

Wave 1 opening lock preserved on bare URL. §9 #3 unblocked: third people playable via HUD picker or URL probe.

---

## What shipped

| Item | Detail |
|---|---|
| Default boot | `world.civ[0]='vespari'`, `civ[1]='aurion'`, then `reset` — bare load still P41 Helion rank vs Kryos wrecks |
| Civ picker | Three HUD tiles (Helion Compact / Kryos Conclave / Nihiline), left rail below topbar — not a blocking splash |
| Switch flow | Sets `civ[0]`, `civ[1]=enemyCiv(player)` (Nihiline → Kryos), `reset(SEED)`, camera restored to opening look-at |
| URL probe | `?civ=voidmarked` or `?p=voidmarked` applies player civ **before** first reset (Playwright skips click) |
| Opening unique | `uniqueUnit(a)` — Nihiline player spawns `Kind.Shade` (id **6**) in the clash belt |
| Input fix | `pointerdown` on `#topbar` / `#bottom` / `#civpick` no longer captures pointer (HUD buttons work) |
