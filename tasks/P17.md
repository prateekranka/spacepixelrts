# P17 — Opening tableau fills the screen

**Builder:** Composer 2.5 · **Gap from:** `tasks/P16-critic.md` · **Shipped:** 2026-08-16

## Problem

P16 failed on a single gap: the opening shot was ~9 combat sprites in a void (~64% near-black pixels). Silhouettes, HUD, and frame time already passed.

## Changes

### 1. Packed mid-map clash (`src/sim.ts`)

- 8v8 Fighters + both civ uniques (Ravager / Prism) in a tight ~8×6 tile brawl centered on the default camera look-at (`MAP * 0.5`, `MAP * 0.52`).
- Two readable clumps: Helion (west) vs Kryos (east), ~3.5 tiles apart — not a single pile.
- Removed erroneous extra Shade spawn.
- Workers and bases unchanged at map edges.

### 2. Terrain is a place (`src/atlas.ts`, `src/sim.ts`)

- Brightened `void`, `dust`, `rock` palette; added `dustE` edge highlight.
- `drawTile` draws isometric diamond edges on dust/rock/resource tiles.
- `genMap` dust threshold lowered (0.62 → 0.46) for more walkable ground.
- `stampOpeningGround()` — dust pad under the clash plus ore/gas/solar patches at the brawl edges.

### 3. Fog reveals the fight on tick 0 (`src/sim.ts`)

- `revealOpeningVision()` — 9-tile radius circle at mid-map, applied after `updateFog()` in `reset()`.
- `refreshVis()` updates enemy `e.vis` after the reveal.

### 4. Unchanged

- `halfH` ≈ 5, unit scales, magenta team key, nearest-neighbor filtering.
