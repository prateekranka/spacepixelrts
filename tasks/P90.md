# P90 — Unit & Building Character Redesign

## What changed

Rewrote `src/sprite-sdf.ts` so each **role owns its full silhouette** instead of sharing a per-civ blob body with a tiny overlay.

### Architecture
- Added `onLine()`, `inTri()`, and civ palette helpers (`civDark` / `civMid` / `civHi`).
- `unitRole()` now dispatches to dedicated draw functions that paint the **entire** character.
- `unitBody()` is only used for corpse fallback; living units no longer composite body + overlay.
- `spriteCore()` routes units straight to `unitRole()`.

### Units (all 3 civs × 7 roles)
| Role | Silhouette tell | Weapon / tool |
|------|-----------------|---------------|
| **Worker** | Hunched torso + short legs; civ body family (hex / diamond / tattered box) | Dominant **ore crate** on the right shoulder, drill arm left, hard-hat beacon |
| **Scout** | Low horizontal wedge hull | **Sensor dish** left-front, pointed nose right, exhaust glow rear |
| **Fighter** | Upright braced stance, wide shoulders | **Rifle barrel** extending forward-right, helmet + stock |
| **Siege** | Very wide tread base (tank read) | Elevated **cannon** angling up-right, turret block |
| **Ravager** | Low hex beast, lunging posture | Forward **scythe claws** (animated lunge on bob) |
| **Prism** | Floating diamond (no legs), hover bob | **Focus lens** + beam line right |
| **Shade** | Thin vertical cloak, asymmetric tatters | Single **glowing eye**, dagger line |

Civ identity is material only: hive-round (vespari), crystal-angular (aurion), void-tattered (nihiline).

### Buildings (all 3 civs × 4 types)
- **Hall** — walls + roof tier + central spire/mast; small arched **door** (team-color `paintMag` panel only).
- **House** — rectangular walls, pitched/domed **roof** above wall line, lit window.
- **Barracks** — crenellated military deck, arched gate, flanking **weapon racks**, banner pole.
- **Unique** — Spore Nursery (organic pods), Refraction Spire (prismatic tower + fins), Umbra Relay (void antenna + orb crown).

## Verification
- `npx tsc --noEmit` — clean
- `npm run build` — succeeds
- Gallery screenshot (`critic/out/p90-gallery.png`) shows worker crate, scout dish, fighter rifle, siege treads+cannon, ravager claws, and distinct building roofs/doors at zoom.

## Least confident read
**Scout** — at default opening zoom the low, wide hull can still compress into a small horizontal smear next to fighters. The sensor dish and exhaust help when zoomed in, but it is the role most likely to be confused with a generic speed unit at a glance.
