# P81 — Procedural terrain shader with dune banding and sun rims

**Builder:** Composer 2.5 · **Version:** `0.7.1-proc` · **Judged:** 2026-08-16

**Live:** https://spacepixelrts.pages.dev

Ground no longer uses a baked canvas atlas stamped onto a flat plane. `mapMesh` is a `ShaderMaterial` with value-noise weather, two-scale dune ripple banding, quantized elevation steps, and a 1px sun rim. Tile types from `world.tiles` tint the shader via a nearest-filtered `DataTexture` — Rock/Ore/Gas/Solar/Void remain readable at RTS zoom.

---

## What shipped

| Item | Detail |
|---|---|
| `src/terrain.ts` | `buildTerrainMesh` — GLSL VS/FS, tile `DataTexture`, scatter-rock decal mask |
| `src/render.ts` | `buildMap` delegates to procedural terrain; canvas bake removed |
| Dust | Value noise + dual sin ripples → 5-step quantized elevation; sun rim on lit step edges |
| Rock | Boulder mask in tile-local space + flank rocks from tile data + legacy scatter decals |
| Resources | Subtle ore/gas/solar ground tint on dust base (gems still entity sprites) |
| Perf | No per-frame tile texture rebuild; nearest filter, no mipmaps |
