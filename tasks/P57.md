## Gap (from P54)

§9 #2 — strikes were visually sold (P51–P53 muzzle/impact sparks, combat HP) but **silent**. `Sfx` had select/move/attack/build order cues only; combat never invoked them.

---

## Changes

| Area | Result |
|---|---|
| **`Sfx.hit()`** | Short triangle thud (380 Hz, 32 ms, gain 0.022) — distinct from low `attack()` order cue. Rate-limited **8 voices/s** (125 ms gate). |
| **`Sfx.muzzle()`** | Optional pop on bolt spawn (920 Hz, 16 ms). Lighter gate (80 ms). |
| **`World.onHit` / `onMuzzle`** | Sim callbacks only — no Three.js import. Wired in `main.ts`: `world.onHit = () => { sfx.hit(); hitSfx++; }`. |
| **Melee** | `tryStrike` calls `onHit` when melee damage lands. |
| **Ranged** | `stepBolts` calls `onHit` on impact; `spawnBolt` calls `onMuzzle`. |
| **Probe** | `window.__STARHOLD__.hitSfx` counts hit invocations (Playwright cannot hear audio). |
