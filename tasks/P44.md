## Problem (from P43)

P43 unblocked Worker training but the AoE2 command feel still lacked **epochs**. DESIGN §4: Spark start; Orbit costs **400 Ore, 80 Charge, 40s**; Nexus cannot train while aging. Yard production (Fighter, Spore Rider) gates on Orbit; Siege and civ uniques gate on Dominion.

---

## Changes

| Area | Fix |
|---|---|
| **`TeamEco`** | `epoch` (0 Spark · 1 Orbit · 2 Dominion · 3 Apex) and `ageT` (seconds remaining). Both teams start Spark. Published on `window.__STARHOLD__.teams[]`. |
| **`World.tryAgeUp(team)`** | Spark only; ore ≥ 400, charge ≥ 80; not aging; Hall not training. Spends resources, sets `ageT = 40`. |
| **`World.stepAge()`** | Decrements `ageT`; on complete sets `epoch = 1` (Orbit). |
| **`tryTrain`** | Hall returns false while `ageT > 0`. Barracks respects `minTrainEpoch()` gates. |
| **`hud.ts` Hall** | **Age Up** button (`Spark → Orbit`, sub `400 ore · 80 chg`). Disabled if unaffordable, aging, or Orbit+. Shows countdown while aging. Worker/Scout disabled while aging. |
| **`hud.ts` Yard** | Fighter (and Spore Rider if Nihiline) require Orbit; Siege / Solar Lance / Glacier Titan require Dominion — disabled with epoch name subtitle. |
| **`content.ts`** | `EPOCH_NAME`, `minTrainEpoch()` shared by sim + HUD. |
| **`main.ts`** | `VERSION = 0.3.1-wave2`. |

Opening tableau units and cinematic Yard **unchanged** (P41 look locked). Pop/housing from P43 unchanged.
