# P43 — Unblock training (pop under cap)

**Builder:** Composer 2.5 · **Bar:** empire loop can start from opening skirmish · **Shipped:** 2026-08-16

**Live:** https://spacepixelrts.pages.dev · **Version:** `0.3.0-wave2`

---

## Problem (from P42)

Player opened at **22/20 pop** — `tryTrain` refused every queue. Kryos opening wrecks (`hp <= 0`, `corpseT > 0`) still counted toward pop. Home pad had only one Habitat (+5); mid-map camp houses were not enough to cover the tableau army.

---

## Changes

| Area | Fix |
|---|---|
| **`recountPop`** | Skip entities with `hp <= 0` or `corpseT > 0` for pop (and cap only from living buildings). Opening Kryos wrecks no longer occupy housing. |
| **`spawnScenario`** | Two extra `Kind.House` at each **home pad** only (player ~12.0,12.0 + 8.8,9.0; enemy mirrored). Mid-map houses / gem / workers untouched. |
| **`hud.ts`** | Train buttons on Hall and Yard disable when `pop + cost > cap`; subtitle shows **pop cap**. |
| **`input.ts`** | Building pick uses effective radius **≥ 2.2** so Nexus tap after minimap jump selects reliably. |
| **`main.ts`** | `VERSION = 0.3.0-wave2`; probe exposes `__STARHOLD_INPUT__`, `__STARHOLD_VIEW__`, `__STARHOLD_WORLD__` for Playwright harness. |

Cap math after fix: Nexus +10, four home Habitats +20 = **30** per team. Opening player pop **22 < 30** (room for Worker + Fighter).
