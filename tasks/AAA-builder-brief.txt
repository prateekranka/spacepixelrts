### Asset layout (already committed, do not regenerate)

`public/front-end/civilizations/<civ>/<mode>/` where civ in {sunweaver, gravemark},
mode in {menu, loading}. Each civ dir has `manifest.json`:
`{ <mode>: {scene, mode, canvas:{width,height}, assets[], sprites[], twinkles?,
fallbackPalette[]} }` (see spec schema; this build additionally uses per-sprite
`places[].box` FIT-CONTAIN and optional `drift`).

Manifest semantics (implement exactly):

- `assets[]` entries: `{file, kind: 'cover'|'rect', blend: 'source-over'|'screen'}`
  plus for 'rect' a `rect: [x,y,w,h]`. `cover` = scale-to-cover canvas (nearest
  neighbor), center-crop. `rect` = FIT-CONTAIN inside rect preserving aspect ratio,
  centered in the rect. Draw order = manifest order. `screen` blend = additive
  (use `globalCompositeOperation = 'screen'`).
- `sprites[]` entries: `{file, frames: [[x,y,w,h],...], frameRate, blend, drift?,
  places: [{frame: -1|index, box: [x,y,w,h], anchor?: [x,y,w,h]}]}`.
  - `frames` are source rects in the sheet PNG (1920x1080 space). frame index =
    floor(frame * frameRate / 12) % frames.length, looping; a `place` with
    `frame >= 0` pins the sprite to that frame; `frame === -1` animates.
  - Each place draws the (possibly animated) frame FIT-CONTAIN into `box`.
  - `drift: {amplitude, phase}` — vertical bob via `sceneMotionOffset(visualFrame,
    amplitude, phase, reducedMotion)` applied to the place's box y.
- `twinkles`: `{mask, fps}` — the mask is a white 'L' PNG covering the canvas;
  draw it with `globalCompositeOperation = 'screen'` at `globalAlpha` pulsing
  between `[0.35, 0.9]` at the given fps (use quantizeSceneTime with fps to step).
  Non-essential; keep it cheap. With reducedMotion: alpha = 0.9.
- `fallbackPalette`: if assets fail to load, paint a flat muted gradient
  (palette[0] top → palette[1] horizon → palette[4] bottom) so the menu never
  shows a blank canvas.

### Runtime behavior

- Lazy load per (civ,mode): fetch `front-end/civilizations/<civ>/<mode>/manifest.json`
  (relative path, no leading slash required), then decode all referenced images
  into `ImageBitmap` when available (fallback `HTMLImageElement`). Cache the pack.
  If a request fails: use fallback paint + `data-art-ready="false"`.
- On `mount`: paint fallback immediately, async-load the initial pack, repaint
  when ready, then run the 12 fps rAF loop (existing `schedule()` pattern).
- `setFaction`/`setMode`: swap packs when different; do NOT reset the rAF loop.
- `reducedMotion`: always draw frame 0; strips use frame 0; drift = 0;
  twinkles alpha = 0.9.
- Draw all stats into the SINGLE existing canvas; no extra DOM nodes.
