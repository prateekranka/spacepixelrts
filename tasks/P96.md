# P96 — Procedural terrain elevation (iterate)

## Gap closed

Elevation must **read as 3D iso terrace walls** (dark cliff faces under raised mauve dust tops) with **walkable ±1 ramps** and **blocking cliffs** on Δ≥2 steps. Opening clash pad stays flat; fighters stay visible.

## Sim pipeline order (`src/sim.ts`)

```
generateHeightmap()
stamp patches / opening / clearBase
flattenHeightPads()          # pads = 0
skirtRampsAroundPads()       # 2-tile ring: height≥2 → 1
applyHeightCliffs()          # LAST — mark high tile Rock + block
```

### Height gen

- FBM + terrace on Dust (Void stays height 0).
- Valley corridor `t ≈ 0.34–0.56`, `perp < 5.5` (mid-map, flattened on opening pad).
- Ridge near enemy approach `t ≈ 0.78–0.92`; ramp gap `perp 4–6` → level 1; core `perp < 4.2` raised.

### Cliffs

- Compare 4-neighbors **including Void** for Δheight; mark **high** tile only.
- Skip tiles inside `isHeightPad` (opening + both bases).
- `terraceStore` clamps to levels **0–3**.

### Ramps

- `skirtRampsAroundPads`: expanded 2-tile ring outside each pad clamps `height ≥ 2` → `1`.

## Visual (`src/terrain.ts`, `src/height.ts`)

- Vertex shader samples `uHeight` at **world XZ from `modelMatrix`** (matches CPU `height[x + z*MAP]`).
- `HEIGHT_SCALE = 1.1`; P91 quiet mauve dust on terrace tops; `vSlope` darkens cliff faces.

## Sprites (`src/render.ts`)

- `groundY` bilinear on `world.height` — aligns with mesh after UV fix.

`VERSION` → `0.9.3-iso`.
