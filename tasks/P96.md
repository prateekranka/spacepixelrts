# P96 — Procedural terrain elevation

## What changed

### Height storage (`src/sim.ts`, `src/height.ts`)

- Added `World.height: Uint8Array` (MAP×MAP, levels **0–3**).
- `generateHeightmap()` fills from 4-octave value-noise FBM, then terraces per spec:
  - `band = h * 4` → `level = floor(band)` → `ramp = min(2 * fract(band), 1)` → `store = round(h * 3)`.
- **Forced height 0** on opening clash pad (`stampOpeningGround` bounds) and both `clearBase` nexus pads via `flattenHeightPads()`.
- **Ridge + valley** along the base-to-base diagonal: valley corridor at `t ≈ 0.34–0.56` (low), ridge wall at `t ≈ 0.6–0.8` (high).
- **Cliffs block pathing:** 4-connected neighbors differing by **≥ 2** levels → both tiles `Tile.Rock` + `block=1` (skipped on pads). ±1 stays walkable dust ramp.
- Removed legacy random rock blobs; elevation cliffs are the primary blockers.

### Visual (`src/terrain.ts`)

- Terrain mesh: `PlaneGeometry(MAP, MAP, MAP, MAP)` with vertex displacement from `uHeight` texture (`HEIGHT_SCALE = 0.9`).
- Fragment shader blends P91 quiet mauve dust with `vSlope` cliff darkening on steep faces; rock tiles get extra ink on cliffs.
- Fog overlay uses the same displaced mesh (`buildFogMesh`) + `0.06` y bias so fog hugs ridges.

### Sprites (`src/render.ts`)

- Units, buildings, props, shadows lifted by `groundY(x,z)` (bilinear sample of `world.height`).
- `pick()` ray-marches along the unprojected view ray until it hits the heightfield (no flat y=0 plane).
- Overlay `project()` uses lifted ground y for selection rings, flags, HP bars.

`VERSION` → `0.9.2-iso`.

## Opening pad

Opening clash area stays **height 0** and flat: `flattenHeightPads()` runs after all stamps; cliff marking skips pad tiles. Fighters remain visible on the dust valley floor (`critic/out/p96.png`).
