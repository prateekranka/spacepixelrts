# P92 — Buildings as places (GAP 2)

## Problem
Buildings rendered as black slabs with a gold team sticker. `art-reference.ts` had the correct roof/wall/door technique but the running game sampled the wrong atlas region.

## Root cause
**Atlas Y mismatch.** `buildSpriteAtlas()` placed buildings at `row * 64` (e.g. hall at y=640) while canvas height was only `unitRows*32 + 4*64 = 576`. The shader sampled `uBuildingRow * uHallCell` — same wrong offset — so GPU hit empty/black atlas pixels. Halls also used 32px column stride for X while occupying 64px.

## Fix
1. **`src/sprites.ts`** — Port art-reference building anatomy to full roster (hall/house/barracks/unique × 3 civs):
   - Brighter wall tones above quiet-dust terrain
   - Pitched roof (wide eaves, narrow peak), 3-tone walls
   - Chunky inset door (`drawDoor`) and 2×2 lit windows (`drawWindows`)
   - Small MAG banner trim only (`drawBanner`)
   - Civ motif subordinate to architecture
2. **`src/sprites.ts`** — Atlas blit: `buildingBaseY = unitRows * ATLAS_CELL`; hall `dx = civ * 64`.
3. **`src/sprite-sdf.ts`** — Shader `rowY = uUnitRows * uCell + (kind - 10) * uHallCell`; hall `canvasX = col * uHallCell + vUv.x * spr`.
4. **`src/main.ts`** — `VERSION = 0.8.1-art`.

## Verify
- `npx tsc --noEmit` ✓
- `npm run build` ✓
- `critic/out/p92.png` — opening camera: domed roofs, wall planes, doors at base
- `critic/out/p92-hall.png` — player hall zoom: green roof, grey walls, cyan windows, inset door
