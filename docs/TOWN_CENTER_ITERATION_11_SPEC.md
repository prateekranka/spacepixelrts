# Sunweaver Town Center — Iteration 11 Reference Palette

Use the exact palette printed in the supplied concept sheet on the corresponding surfaces.

## Exact mapping

- Exterior ivory stone: `#F0E0B6`
- Gold/brass trim: `#D9B26E`
- Outside landscaping / foliage highlights: `#7AB591`
- Deep-blue banners: `#1E3A6D`
- Cyan crystal and energy: `#36C9FF`

## Application

- Set the primary exterior stone constant and main wall material to `#F0E0B6`.
- Keep a small light/shadow value range derived from that ivory for depth, but do not shift the exterior to gray-brown.
- Set the primary gold constant to `#D9B26E`. Keep a darker aged-gold shadow material derived from it.
- Set foliage highlights to exactly `#7AB591`; use a darker sage derivative for shaded leaves.
- Keep banners centered on `#1E3A6D` and cyan systems centered on `#36C9FF`.
- Set the saturated mandorla material to `#36C9FF`.
- Do not paint stone walls sage green.
- Do not recolor the neutral review background.
